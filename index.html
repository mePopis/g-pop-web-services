Go for G Pop!

A learning project inspired by GOV.UK page layouts, built with HTML, CSS and JavaScript. Links and feedback tools are provided for demonstration.

Contents

  2. Interactive features

Page structure and layout

This project explores how clear headings, breadcrumbs and contents links help visitors find their way around a page. The layout is inspired by GOV.UK, with my own G Pop branding.

Interactive features

JavaScript powers the dark mode switch, remembers the selected theme when browser storage is available, and displays messages when visitors try the feedback buttons or demo report form. The print button opens the browser’s print dialog.

Accessibility and navigation

A skip link lets keyboard users move straight to the main content. Visible focus outlines show which link or control is selected, while labelled form fields and status messages help make the interactive features easier to use.
